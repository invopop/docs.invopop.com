<Accordion title="How to read the mapping tables">
Each row is one field of the government format. The tables list every field of the format, also the fields that Invopop does not support.

| Column | Meaning |
|---|---|
| **ID** | A stable number for the row. Use it in tickets and reviews, for example `MX-INV-H07`. |
| **CFDI field** | The field in the government XML. `@` is an attribute. |
| **CFDI** | The requirement level of the government format. |
| **Format** | The data type, the maximum length or the SAT catalog. |
| **GOBL field** | The field in your GOBL document that gives the value. |
| **You send** | The requirement level for your system. |
| **Rule** | The condition, the default value or the validation. |

| Level | Meaning |
|---|---|
| **M** | Mandatory. The field must have a value. |
| **C** | Conditional. The field is mandatory when the condition in the "Rule" column is true. |
| **O** | Optional. |
| **Auto** | Invopop or GOBL sets the value. Do not send it. |
| **No** | Not supported. Invopop does not write this field. |
</Accordion>
