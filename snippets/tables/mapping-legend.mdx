<Accordion title="How to read the spec">
Each row is one field of the government format. Select a row to see its details.

| Label | Meaning |
|---|---|
| **Mandatory** | The field must have a value. |
| **Conditional** | The field is mandatory when its condition is true. |
| **Optional** | You can omit the field. |
| **Auto-filled: Always** | Invopop or GOBL sets the value. Do not send it. |
| **Auto-filled: If empty** | Invopop or GOBL gives a default when you do not send the field. |
| **Not supported** | Invopop does not write this field. |

The ID of a row does not change. Use it in tickets and reviews, for example `MX-INV-H08`.

The spec shows the standard behavior of Invopop. It does not include rules that are specific to one customer.
</Accordion>
