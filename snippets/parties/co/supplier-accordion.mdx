<Accordion title="Colombia supplier">
  The name, NIT with the verification digit, and an email address are required for registration. The example also includes the address and the `co-dian-municipality` extension identifying where the supplier is registered, and uses Alegra's sandbox NIT so it can be registered in the sandbox.

  <Supplier />

  <Note>
    If the supplier has special tax obligations, set them with the [`co-dian-fiscal-responsibility`](https://docs.gobl.org/addons/co-dian-v2) extension: `O-13` _Gran contribuyente_, `O-15` _Autorretenedor_, `O-23` _Agente de retención IVA_, or `O-47` _Régimen simple de tributación_. It defaults to `R-99-PN` when none apply.
  </Note>
</Accordion>
