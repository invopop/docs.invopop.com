  <Accordion title="How do I register a supplier with AT?">
    Run the AT Register Supplier workflow on the supplier, provide their AT web-service credentials, then register at least one series per document type they'll issue. Both can be done in the supplier portal or through the API ([credentials](/api-ref/apps/at-pt/credentials), [series](/api-ref/apps/at-pt/series-register)). Each series gets a validation code from the AT, used to build the ATCUD on every document. See [Register a supplier](/guides/pt-at-supplier).
  </Accordion>

  <Accordion title="What credentials does AT require to authenticate a supplier?">
    An AT web-services sub-user (username and password) created in the AT portal, in both models. It always needs the `WSE` permission, to register series; add `WFA` if documents are reported in real time.
  </Accordion>

  <Accordion title="How are supplier credentials stored in Invopop for Portugal?">
    Invopop stores the AT web-service credentials encrypted at rest, in both models: they're needed to register series, and for real-time reporting. In the SAF-T model, the supplier (or their accountant) also downloads the monthly SAF-T file and uploads it to the AT's portal.
  </Accordion>
