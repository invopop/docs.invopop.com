  <Accordion title="How do I register a supplier with Smart Receipts?">
    Create the supplier party with its Partita IVA and run the Smart Receipts Register Supplier workflow. The workflow returns a signed registration link in the silo entry's meta. Open the link (or share it with the supplier) and submit the supplier's AdE credentials. Once the form is accepted, the post-registration workflow runs and the supplier can start issuing receipts. See the [supplier registration guide](/guides/it-ticket-supplier) for the full steps.
  </Accordion>

  <Accordion title="What credentials does Smart Receipts require to authenticate a supplier?">
    The supplier's own Agenzia delle Entrate portal credentials: the password and PIN they use at ivaservizi.agenziaentrate.gov.it, together with their Partita IVA and *codice fiscale*. Only a representative of the supplier can generate these. They are submitted through the registration link and passed securely to our local partner, who uses them to transmit receipts to the AdE on the supplier's behalf. Invopop stores the *codice fiscale* on the party but never stores the password or PIN.
  </Accordion>

  <Accordion title="How often do the supplier's AdE credentials need to be renewed?">
    Every 90 days. The supplier must first renew the credentials on the AdE portal, then resubmit them through the same registration link (or via the API `PUT` to the link) so receipt issuance is not interrupted.
  </Accordion>
