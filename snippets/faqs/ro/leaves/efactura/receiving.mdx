  <Accordion title="Which invoices are imported?">
    Invoices other companies issued to the registered party and that ANAF made available in its SPV, from the moment the party completed registration. Invoices received before registration are not imported.
  </Accordion>

  <Accordion title="Do I need to run the import workflow myself?">
    No. The **RO Sync Received Invoices** workflow creates one import job per received invoice, using the workflow set as **Import Workflow** in its **Receive all new invoices from RO e-Factura** step. Don't run the import workflow directly.
  </Accordion>

  <Accordion title="What happens if the sync stops for a while?">
    Each sync picks up from where the last successful one finished, so no invoice is missed. ANAF keeps messages for 60 days, so a party that stops syncing for longer loses the older ones.
  </Accordion>

  <Accordion title="What is stored for an imported invoice?">
    The ANAF archive is kept in Invopop's database, and a new invoice entry is created in the silo with the invoice converted to GOBL. The workflow then sets the folder and state, typically **Invoices · Expenses** and `Registered`.
  </Accordion>
