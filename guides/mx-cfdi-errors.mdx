Use this page when a document fails with a `GOBL-MX-CFDI-...` code. Search the page for the code. The last column gives the row of the spec that has the full rule.

GOBL makes these checks when you upload or build the document, before Invopop sends it to the PAC. A document that passes them can still fail at the PAC. For example, the PAC rejects a customer name that is different from the SAT registry.

| Code prefix | Document | Spec |
|---|---|---|
| `GOBL-MX-CFDI-BILL-INVOICE-` | Invoice, credit note, global invoice | [Invoice](/guides/mx-cfdi-invoice), [Parties](/guides/mx-cfdi-parties) |
| `GOBL-MX-CFDI-BILL-PAYMENT-` | Payment receipt | [Payment receipt](/guides/mx-cfdi-payment) |
