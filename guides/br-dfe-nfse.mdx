## Introduction

An NFS-e (_Nota Fiscal de Serviços Eletrônica_) is the electronic invoice for services. The issuer's municipality authorizes it, with its own rules. You can find [the full list of supported municipalities here](https://tecnospeed.com.br/plugdfe/nfse/#homologacao).

Which document to issue, how documents are checked and the environments are in the [DF-e overview](/guides/br-dfe). For onboarding suppliers, see the companion guide: [DF-e supplier registration](/guides/br-dfe-supplier).

## Prerequisites

To issue an NFS-e, you will need:

- A registered supplier: follow the [DF-e supplier registration guide](/guides/br-dfe-supplier) to connect the Documentos Fiscais Eletrônicos Brazil app and register the supplier's certificate before issuing.
- Customer details.
- Details of the services provided:
  - quantity,
  - price,
  - applicable tax rates (ISS, PIS, COFINS, etc.), and,
  - service code (_Código Item Lista Serviço_) as defined by the municipality.
- To have chosen an invoice series

## Cancel an invoice

Run the "DF-e cancel service invoice (NFS-e)" workflow over the silo entry you want to cancel. On success, the entry will be set to `Void`.

The cancel action accepts optional parameters. Set them as a default on the workflow step, in the step's configuration page in the Console. Or pass them as job arguments when [creating the job via the API](/api-ref/transform/jobs/create-a-job-put). Job arguments take precedence over the step configuration.

| Parameter | Job argument | Notes |
|---|---|---|
| Cancellation reason | `nfe-br-cancel-reason` | Free-text reason for the cancellation. Defaults to the system default when omitted. |
| Cancellation code | `nfe-br-cancel-code` | Municipality-specific cancellation code, for example `9` for "Outros" in the National NFS-e system. Defaults to the system default when omitted. |

```json
{
  "workflow_id": "...",
  "silo_entry_id": "...",
  "args": {
    "nfe-br-cancel-reason": "Cancelamento a pedido do Prestador",
    "nfe-br-cancel-code": "9"
  }
}
```

<Info>
  NFS-e cancellations are subject to the rules of each municipality. Some require a specific cancellation code.
</Info>
