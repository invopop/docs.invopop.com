A global invoice (_factura global_) is a CFDI of type `I` that adds together the sales to consumers who did not ask for an invoice. Each sale of the period is one line.

| | |
|---|---|
| **GOBL document** | [`bill/invoice`](https://docs.gobl.org/draft-0/bill/invoice), type `standard`, tag `global` |
| **Regime and addon** | `$regime` [`MX`](https://docs.gobl.org/regimes/mx), `$addons` [`mx-cfdi-v4`](https://docs.gobl.org/addons/mx-cfdi-v4) |
| **Government format** | CFDI 4.0, `cfdv40.xsd`, node `InformacionGlobal` |
| **Workflow** | The same as an invoice. See the [CFDI issuing guide](/guides/mx-sat-issuing). |
| **Base spec** | [Invoice](/guides/mx-cfdi-invoice). This page lists only the differences. |
| **Time limit** | 24 hours after the period closes (rule 2.7.1.21 of the RMF 2026) |
