A credit note in Mexico is a CFDI of type `E` (Egreso). It decreases the amount of an invoice: a return, a discount after the sale, or a correction. It does not cancel the invoice. To remove an invoice, [cancel it](/guides/mx-sat-cancelling).

| | |
|---|---|
| **GOBL document** | [`bill/invoice`](https://docs.gobl.org/draft-0/bill/invoice), type `credit-note` |
| **Regime and addon** | `$regime` [`MX`](https://docs.gobl.org/regimes/mx), `$addons` [`mx-cfdi-v4`](https://docs.gobl.org/addons/mx-cfdi-v4) |
| **Government format** | CFDI 4.0, `cfdv40.xsd` |
| **Workflow** | The same as an invoice. See the [CFDI issuing guide](/guides/mx-sat-issuing). |
| **Base spec** | [Invoice](/guides/mx-cfdi-invoice). This page lists only the differences. |
