Norway handles e-invoicing through the Peppol network. The national EHF (Elektronisk HandelsFormat) standard has fully converged with Peppol BIS Billing 3.0, which has been **mandatory for all public sector suppliers since April 2019**. A proposed B2B mandate targets mandatory sending by 2028 and receiving by 2030. For comprehensive information about Peppol features and capabilities, please refer to our [Peppol Guide](/guides/peppol).

## Suppliers already on Peppol

Many Norwegian companies are already registered in ELMA with another Access Point, because public sector suppliers have used EHF over Peppol since 2019. A participant can only have one receiving Access Point, and Invopop does not take over an existing registration automatically, so the **Register party on Peppol** step fails for these suppliers.

Before you register them, ask the supplier to request a **migration key** from their current Access Point, then pass it as the `peppol-migration-key` argument when you run the registration step. This moves the participant to Invopop with no interruption in delivery. See [Migrating a participant from another provider](/guides/peppol#migrating-a-participant-from-another-provider) for the full steps and the alternative if no key is available.
