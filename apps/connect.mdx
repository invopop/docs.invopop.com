	The Connect app brings the documents your suppliers and systems send you into Invopop. Each **endpoint** receives documents on one channel, either an HTTP address that other systems post files to, or an email address that suppliers send invoices to. Every file an endpoint receives starts a job in the workflow you choose for it.

	The workflow's **Import document** step turns the file into a GOBL invoice in your workspace. GOBL, UBL and CII documents, including PDFs that carry them (Factur-X, ZUGFeRD), are converted as they are. Other PDFs and images are read with AI. The step grades every import, so the workflow can send the invoices that need a person's check one way and the rest another.

	Everything an endpoint receives is listed in the app, with the jobs it started and the original files.

	#### Key features

	* **Workflow automation:** Every document an endpoint receives starts a job in the workflow you choose.
	* **HTTP endpoints:** Post files to an endpoint's address, protected with a bearer token, basic credentials or an HMAC signature.
	* **Email endpoints:** Use an `@invopop.email` address, or receive on your own domain through Resend, SendGrid or an IMAP mailbox. Only senders you allow, with a proven domain, are taken.
	* **One job per invoice:** An email with several invoices, or a PDF holding several, starts one job for each. An XML invoice and its PDF stay together.
	* **AI reading:** PDFs and images without embedded data are read with AI, which checks the amounts and lists what it was unsure of.
	* **Graded results:** Each import ends as `low` (check it first), `high` (read with AI, nothing to check) or `parsed` (converted as it was).
	* **Rules for the AI:** Short instructions, grouped in profiles, tell the AI about your suppliers and documents, and can set the GOBL addon.

	Check out the [Connect guide](/guides/connect) to set up your first endpoint and import a document.
