---
title: "Authentication"
icon: "lock-a"
description: Generate an access token to start using an Invopop workspace.
---

Invopop API keys are created in [Admin](https://access.invopop.com) under **API keys**, or by clicking <kbd>Manage API keys</kbd> from **Configuration → API keys** in the [Console](https://console.invopop.com). Click <kbd>New API key</kbd>, choose the workspace the key will act on, give it a name and an optional description, and tick the **Read** or **Admin** permission for each service the key needs (All services, Access, Transform, Silo). The token is shown once on creation. For security reasons, we don’t store it. Copy it now, or you’ll need to create a new API key if it’s lost. See [API keys](/console/api-keys) for the full permission model.

<Tip>
  Invopop uses JSON Web Tokens. If you're interested in seeing the contents, head over to [JWT.io](https://jwt.io) and paste your token to see what's
  inside.
</Tip>

Tokens must be included in the `Authorization` HTTP header in all requests as a type `Bearer`.

Test everything is working correctly using the [ping](/api-ref/utils/ping)
endpoint and curl:

```bash
$ curl -H "Authorization: Bearer [token]" https://api.invopop.com/utils/v1/ping

{"ping":"pong"}
```
