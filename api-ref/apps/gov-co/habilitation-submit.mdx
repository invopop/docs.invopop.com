---
title: "Submit test set"
openapi: "POST /apps/gov-co/v1/habilitation/{silo_entry_id}"
---

Submits the DIAN habilitación test set using the TestSetId from the DIAN habilitación portal. Alegra emits the test documents to the DIAN on the supplier's behalf, and the workflow's **Wait for DIAN habilitación** step picks up the outcome automatically.

<Note>
  Use this endpoint only after running the supplier registration workflow. It responds `409` when the supplier is already habilitated or a previous habilitación failed. Run the registration workflow again to restart a failed habilitación.
</Note>
