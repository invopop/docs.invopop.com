---
title: "Fetch enablement status"
openapi: "GET /apps/gov-co/v1/entries/{silo_entry_id}/enablement"
---

Returns the supplier's current DIAN enablement state: `status` is omitted until a test set has been submitted, then moves through `pending` to `accepted` or `failed`. When it's `failed`, the DIAN's reason is in the faults of the registration job; see [Failed enablement](/guides/co-dian-registration#failed-enablement).

<Note>
  Use this endpoint to drive your own onboarding UI instead of the hosted portal. The silo entry must belong to the authenticated workspace and have been registered with the Colombia app first.
</Note>
