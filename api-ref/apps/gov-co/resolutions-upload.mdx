---
title: "Upload contingency resolution"
description: "Upload a DIAN contingency numbering resolution for a registered Colombian supplier."
openapi: "POST /apps/gov-co/v1/entries/{silo_entry_id}/resolutions/contingency"
---

Uploads a contingency (_talonario o papel_) numbering resolution for the supplier, so it can [transmit invoices issued during a contingency](/guides/co-dian-invoicing#transmitting-invoices-issued-during-a-contingency). Use the details on the DIAN's form 1876 for the [contingency range](/guides/co-dian-registration#contingency-range).

<Note>
  Contingency resolutions can't be fetched from the DIAN, so they're kept as uploaded. Uploading one with the same prefix again replaces it. The silo entry must belong to the authenticated workspace and have been registered with the Colombia app first.
</Note>
