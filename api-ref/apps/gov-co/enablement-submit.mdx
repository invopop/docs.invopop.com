---
title: "Submit test set"
openapi: "POST /apps/gov-co/v1/enablement/{silo_entry_id}"
---

Submits the DIAN enablement test set using the TestSetId from the DIAN enablement portal. Alegra emits the test documents to the DIAN on the supplier's behalf, and the workflow's **Wait for DIAN enablement** step picks up the outcome automatically.

<Note>
  Use this endpoint only after running the supplier registration workflow. It responds `400` when a test set is already awaiting the DIAN outcome, the supplier is already enabled, or a previous enablement failed. Run the registration workflow again to restart a failed enablement.
</Note>
