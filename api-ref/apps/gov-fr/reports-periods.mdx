---
title: "List e-reporting periods"
description: "List a party's Flux 10 report periods, most recent first."
openapi: "GET /apps/gov-fr/v1/reports/{siren}/periods"
---

Each period is one submission window for a `(kind, role)` tuple; a report generated again for the same window, for example after a PPF rejection, appears as a separate period with an incrementing `sequence`.

Filter by report kind with `kind`. Paginate with `offset` and `limit` (default `50`, maximum `200`). When more results remain, the response carries a `next_offset` to pass on the next call; it is omitted on the last page.
