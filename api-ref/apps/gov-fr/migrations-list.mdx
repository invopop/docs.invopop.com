---
title: "List migrations"
description: "List the workspace's takeover requests with other Plateformes Agréées, newest first."
openapi: "GET /apps/gov-fr/v1/migrations"
---

Returns one item per address in every migration involving the workspace, newest first, in both roles: `outgoing` when Invopop takes over an address from another PA, and `incoming` when another PA asks to take over one registered through Invopop. 

Each item's `status` gives the outcome for that address: `pending`, `accepted`, `rejected` or `failed`. Its `decisions` list the answers given so far: yours on an incoming item, the old PA's on an outgoing one.

Paginate with `offset` and `limit`, which count items rather than requests, (default `25`, maximum `200`). When more results remain, the response carries a `next_offset` to pass on the next call; it is omitted on the last page.
