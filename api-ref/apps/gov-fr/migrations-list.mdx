---
title: "List migrations"
description: "List the workspace's takeover requests with other Plateformes Agréées, newest first."
openapi: "GET /apps/gov-fr/v1/migrations"
---

Returns every migration involving the workspace's addresses, in both roles: `outgoing` when Invopop takes over an address from another PA, and `incoming` when another PA asks to take over one registered through Invopop. It is the API version of the France dashboard's **Migrations** tab. See [Moving parties between Plateformes Agréées](/guides/fr-pa-migrations#reading-migrations-through-the-api) for the full flow.

Paginate with `offset` and `limit` (default `50`, maximum `200`). When more results remain, the response carries a `next_offset` to pass on the next call; it is omitted on the last page.
