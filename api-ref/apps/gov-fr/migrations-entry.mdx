---
title: "List a silo entry's migrations"
description: "List every takeover request for the address registered by a silo entry, newest first."
openapi: "GET /apps/gov-fr/v1/migrations/{silo_entry_id}"
---

Returns every migration that names the address registered by the silo entry, open and closed, refused ones included. Each migration carries only that entry's line, so the latest one shows whether its address is waiting for an answer and, once answered, the `decision` sent to the new PA. A silo entry has at most one open migration at a time.

An unknown silo entry, or one from another workspace, returns an empty `migrations` list rather than `404`.

Paginate with `offset` and `limit` (default `50`, maximum `200`). When more results remain, the response carries a `next_offset` to pass on the next call; it is omitted on the last page.
