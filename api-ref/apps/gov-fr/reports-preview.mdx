---
title: "Preview the current window's Flux 10 report"
description: "Build the Flux 10 Report.xml for the current reporting window without storing or sending it."
openapi: "GET /apps/gov-fr/v1/reports/{siren}/preview"
---

Builds the report from everything recorded in the current window so far, so you can check what will be filed before the window closes. Choose the report kind with `kind` (required) and the stream with `role` (defaults to `seller`).

The report is checked against the PPF rules before it is returned. A report that would be rejected answers `422` with the issues found, and an empty window answers `404`.

<Note>
  Nothing is stored or submitted. The preview does not create a report period, so it never appears in the periods list.
</Note>
