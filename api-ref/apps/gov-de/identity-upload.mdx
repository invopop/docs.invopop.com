---
title: "Upload ID document image"
description: "Upload one side of the legal representative's ID document."
openapi: "POST /apps/gov-de/v1/entry/{silo_entry_id}/identity"
---

Stores one side of the legal representative's ID document. Call before `POST /confirm`, which verifies the document.

Call once per side: `front` and `back` for an ID card, or a single `page` for a passport. Uploading the same view again replaces the earlier image.
