---
title: "Issue a Peppol migration key"
openapi: "POST /apps/peppol/v1/entry/{silo_entry_id}/migrate"
---

It does the same as the **Start Peppol migration** (`peppol.migrate`) workflow action: the key is returned in the response and also stored in the entry's meta, under `migration-key`.

Calling it again for the same entry returns the key already issued instead of a new one. Only parties registered to receive documents through Invopop can be migrated; see [Migrating a participant to another provider](/guides/peppol#migrating-a-participant-to-another-provider) for the rest of the process.

<Warning>
Treat the migration key as a credential and share it only with the new provider.
</Warning>
