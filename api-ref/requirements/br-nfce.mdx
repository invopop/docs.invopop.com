Scenarios and how to issue them are in the [NFC-e guide](/guides/br-dfe-nfce). This page lists the fields of every scenario.

**Test a scenario:**

1. Pick the scenario in the request example menu.
2. Copy the cURL command.
3. Replace `<token>` with a sandbox workspace token, then run it.

The build call returns the built document, or the GOBL faults with their codes.
