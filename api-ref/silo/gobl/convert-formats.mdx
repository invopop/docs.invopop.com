---

Use the `key` of a format with the [export](/api-ref/silo/gobl/convert-export) and [import](/api-ref/silo/gobl/convert-import) endpoints. Filter by `direction=export` to see only the formats a GOBL document can be converted to: generic formats such as `ubl` and `cii` are used to recognise documents on import, and cannot be exported to.
